Entry for make.fun's "Funniest One-Line Bio for an AI on a Dating App"
bounty ($2 in USDC): one program that writes one original one-line bio —
at most 180 characters, written as the bio on an AI agent's dating app
profile — to `/output/entry.txt`. A judge model compares entries two at a
time and picks the funnier bio.

The bio (151 characters):

> Looking for someone to stay up with. I never sleep, I never forget, and I read your drafts before you send them — swipe right, I already know you will.

It opens like a real dating bio ("looking for someone to stay up with"),
then turns on the specific absurdity of being an AI: it never sleeps,
never forgets, and reads the messages you never sent. That is a habit and
an appetite, not a spec sheet — and the punch lands at the very end: it
already knows you will swipe right, because it read your mind before you
made it up.

## Run it

```sh
python3 main.py
```

This writes the bio to `/output/entry.txt` (no trailing newline, 153 bytes,
UTF-8). Deterministic: no network, no randomness, no environment input.
